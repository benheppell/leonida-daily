Privacy policy

Last updated 20 November 2026.

clip-engine is a private tool used only by the owner of the Leonida Daily YouTube channel. It is not offered to the public and no one else can sign in to it.

What it accesses

  • YouTube Data API: uploading videos to the owner's own channel and reading their titles, privacy status and view counts.
  • YouTube Analytics API: reading the owner's own channel analytics (views and average percentage viewed) to measure which clips perform.

What it stores

An OAuth refresh token, kept as an encrypted secret, and the channel's own video IDs and performance numbers. It does not collect, store or share data about viewers or any other YouTube users.

Sharing

Data is not sold or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. clip-engine uses the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

YouTube API Services

clip-engine uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Retention and deletion

Video statistics read from the API are deleted after 30 days, in line with the YouTube API Services Developer Policies; only conclusions drawn from them (for example, which hook styles performed better) are kept. To have all stored data deleted, revoke access (below) or open an issue at the contact link; it is deleted within 7 days.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, which deletes the stored token's ability to act.

Contact

Questions: open an issue on github.com/benheppell/leonida-daily.
